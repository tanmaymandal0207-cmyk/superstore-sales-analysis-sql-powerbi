This project presents an end-to-end analysis of retail sales data using SQL and Power BI, based on the Superstore dataset. The objective of the project is to transform raw transactional data into meaningful business insights by applying structured data analysis techniques and intuitive data visualization.

The workflow begins with data cleaning and preprocessing using SQL, where inconsistencies, missing values, and formatting issues are addressed to ensure data reliability. This is followed by exploratory data analysis to understand overall trends in sales, profit, and order behavior across different dimensions such as category, sub-category, region, and time.

Building on this foundation, business-focused queries are developed to answer key questions related to performance and profitability. These include identifying top-performing and underperforming segments, analyzing the impact of discounts on profit margins, and uncovering patterns that influence revenue generation.

The insights derived from SQL analysis are then translated into an interactive Power BI dashboard. The dashboard is designed with a clear structure and logical flow, enabling users to explore high-level KPIs as well as drill down into detailed performance metrics. It emphasizes usability, visual clarity, and business relevance rather than just aesthetic design.

This project demonstrates a complete analytics workflow—from raw data to decision-oriented insights—highlighting skills in SQL querying, data interpretation, and dashboard development. It reflects a practical approach to solving real-world business problems using data.
